## Notes on errors (all reported honestly, never replaced with fake data)

- **GDELT**: DOC 2.0 returns HTTP 429 when rate limited by IP. The adapter retries twice and
  otherwise reports an error; the GEO API is retired (404). No fallback events are fabricated.
- **Finnhub**: free tier returns price 0 for `^VIX`; adapter reports an error instead of
  emitting a fake VIX reading. A paid/entitled key would surface the value.
- **ReliefWeb**: `api.reliefweb.int` returns 403/410 from this network. Kept live because
  other hosts may reach it; status is visible in `/api/health`.
- **PeeringDB**: 429 after repeated testing; now retries with backoff (24 h refresh in sweep).
- **OFAC**: transient network failure; now retries once. Confirmed working in the same session
  with `count=1` on a different run.
